# tg2vk: репост из Telegram в группу ВКонтакте

Каждые 30 минут GitHub Actions забирает новые посты канала [@ipico_news](https://t.me/ipico_news) и публикует их на стене группы [vk.ru/ipico](https://vk.ru/ipico) от имени сообщества.

Переносится текст с хэштегами и ссылками, скрытые ссылки становятся видимыми. К постам с фото и видео бот прикрепляет ссылку на оригинал в Telegram (см. ниже). Правки и удаления постов, а также посты, вышедшие до подключения бота, не переносятся.

## Из чего состоит

- `tg2vk.py`: сам бот, сторонние библиотеки не нужны.
- `.github/workflows/tg2vk.yml`: расписание запуска, канал и группа.
- Секреты репозитория (Settings → Secrets and variables → Actions):
  - `TG_BOT_TOKEN`: токен бота из @BotFather; бот должен быть администратором канала;
  - `VK_GROUP_TOKEN`: ключ доступа группы с правом на стену.

## Проверка

Actions → tg2vk → Run workflow, отметьте «Только проверить настройки». В логе шага «Репост» строки `[ok]` и `[--]` в порядке, при `[!!]` рядом будет подсказка. Если пост не опубликуется, GitHub пришлёт письмо о неудачном запуске.

## Фото и видео

Текст ВКонтакте разрешает публиковать ключом сообщества, а загружать фото только ключом пользователя. Поэтому к постам с фото и видео бот прикрепляет ссылку на оригинал в Telegram.

Чтобы фото загружались в ВК, нужен ключ администратора группы с правом `photos`. Сейчас ВК выдаёт такие ключи через VK ID и только по заявке в поддержку. Если получите, добавьте секрет `VK_USER_TOKEN`, и бот начнёт загружать фото сам. Ключи с сайтов вроде vkhost не используйте: ВК замораживает страницы, на которых их замечает.

## Настройки

Секреты задаются в настройках репозитория, остальное в `tg2vk.yml` (на сервере всё в файле `.env`).

| Переменная | Что это |
|---|---|
| `TG_BOT_TOKEN` | токен бота, секрет |
| `VK_GROUP_TOKEN` | ключ группы, секрет |
| `TG_CHANNEL` | канал: `ipico_news` |
| `VK_GROUP_ID` | группа: `ipico` |
| `VK_USER_TOKEN` | ключ пользователя для загрузки фото, необязательно |
| `FOOTER` | подпись под каждым постом, например `Наш Telegram: https://t.me/ipico_news` |
| `MEDIA_FALLBACK` | `none`, чтобы не добавлять ссылку на оригинал |

## Перенос старых постов

Посты, вышедшие до подключения бота, Telegram боту не отдаёт. Их можно перенести разово: положите рядом с `tg2vk.py` файл `backfill.json` с номерами постов и сроком действия:

```
{"posts": [322, 323, 324, 325, 326], "until": "2026-10-16T12:00:00+03:00"}
```

При следующем запуске бот прочитает эти посты с публичной страницы канала и опубликует их по порядку, а потом займётся новыми. Уже перенесённые посты он запоминает и не повторяет. После срока из `until` файл ни на что не влияет, его можно удалить.

## Расписание

Репозиторий публичный: запуски бесплатны, а секреты никому не видны. В публичных репозиториях GitHub отключает расписание после 60 дней без коммитов, поэтому бот раз в 50 дней сам делает пустой коммит «Поддержание расписания». Если сделать репозиторий приватным, запуски будут расходовать около 1 500 из 2 000 бесплатных минут в месяц.

## Запуск на своём сервере

Если нужен репост сразу, а не раз в полчаса:

```
cp .env.example .env      # заполните
python3 tg2vk.py --check
python3 tg2vk.py
```

Нужен Python 3.8 или новее. Сервер лучше брать за рубежом: из российских дата-центров Telegram часто недоступен (или укажите прокси в `HTTPS_PROXY`). Не запускайте бота одновременно на сервере и в GitHub.
